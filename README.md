# Xposure

**Xposure is an accessible portfolio exposure graph that reveals hidden relationships across asset classes.**

Instead of showing a portfolio only as allocations and percentages, Xposure maps how holdings can still be economically connected underneath — across public equity, private equity, real estate, private credit, and infrastructure.

The goal is simple: make hidden concentration easier to understand, both visually and through audio.

---

## Why Xposure?

A portfolio can look diversified on paper while still having overlapping economic exposure.

For example, a utilities holding may appear unrelated to semiconductors, while data-center demand can connect the two through power infrastructure, capital spending, and supply-chain dependencies.

Xposure turns those relationships into an interactive knowledge graph so users can see how different assets connect and where concentration risk may exist.

---

## Features

- Interactive cross-asset portfolio graph
- Asset class encoded by node shape
- Sector encoded by color
- Exposure relationships encoded through different edge styles
- Backend-generated hidden concentration insights
- Contributing holdings highlighted directly on the graph
- Natural-language portfolio questions with text + spoken answers
- Keyboard-only graph navigation
- Audio narration and sonification for blind and low-vision users
- Pitch maps to sector, while stereo position maps to graph position

The accessibility experience is built into the same graph rather than being a separate mode or alternate interface.

## Architecture

```text
Curated Portfolio Data
        ↓
Tiger Data / PostgreSQL
        ↓
Python Insight Logic
        ↓
FastAPI
        ↓
Snowflake Cortex
        ↓
ElevenLabs
        ↓
React + TypeScript
```

The graph relationships are deliberately curated rather than generated by an LLM. AI is used to explain the relationships and concentration insights, not invent the underlying financial connections.

## Accessibility

Xposure includes an audio-visual exploration mode designed for blind and low-vision users.

Users can:

- navigate holdings entirely with the keyboard
- hear portfolio and risk narration
- trigger sonification by hover, click, or keyboard navigation
- hear sector information through pitch
- hear spatial graph position through stereo panning
- use screen-reader-friendly labels and live regions

A full VoiceOver/NVDA validation pass is still planned.

## Running Locally

### Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Backend runs at:

```text
http://localhost:8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## What's Next

The current hackathon version uses curated one-hop relationships and three demo portfolios.

Future versions could add:

- multi-hop exposure relationships
- temporal graphs showing how exposure changes over time
- live market / filing / news ingestion
- scenario testing by swapping holdings
- user-imported portfolios
- deeper screen-reader validation
